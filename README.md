# WDD 130 Starting Template Repository

This repository is a starting template for students in WDD 130.

## Getting Started

1. Open this folder in VS Code.
2. Open `index.html` in the project root.
3. Run Live Server or open the file directly in your browser.

## Project Structure

- `index.html` — root landing page.
- `styles/` — root CSS files.
- `wwr/` — Whitewater Rafting sample site.
- `Week01/` through `Week05/` — class lesson work.

## Recommended Extensions

- `Live Server`
- `Prettier - Code formatter`
